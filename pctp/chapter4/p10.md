# [문제 10](https://programmers.co.kr/learn/courses/30/lessons/60057)

여기는 문제를 해결하면서 점진적으로 코드를 개선해 나간 과정을 기록하는 공간입니다.

## Version 1

- 가능한 모든 압축 단위(`t_size`)에 대해 전체 탐색을 수행합니다.
- 실제 문자열을 합치는 대신, 각 단계에서 계산된 길이(`t_length`)만을 합산하여 효율성을 높였습니다.
- `remember_cnt`를 통해 연속되는 패턴의 횟수를 추적하고, 2회 이상 반복될 경우 숫자의 길이를 길이에 더해줍니다.
- 루프가 끝난 후 마지막으로 남은 `remember_cnt`에 대한 처리도 포함되어 있습니다.

```python
def solution(s):
    min_length = len(s)
    for t_size in range(1, len(s) // 2 + 1):
        t_length = len(s) - (len(s) // t_size) * t_size

        remember = ""
        remember_cnt = 1

        for idx in range(0, len(s) // t_size * t_size, t_size):
            if remember != s[idx:idx + t_size]:
                t_length += t_size # new token found
                remember = s[idx:idx + t_size]

                if remember_cnt > 1:
                    t_length += len(str(remember_cnt))

                remember_cnt = 1
            else:
                remember_cnt += 1

        if remember_cnt > 1:
            t_length += len(str(remember_cnt))

        if t_length < min_length:
            min_length = t_length

    return min_length
```

## Version 2

- 리스트 컴프리헨션을 사용하여 문자열을 `t_size` 단위의 토큰 리스트로 미리 분리합니다.
- `zip()` 함수를 활용하여 현재 토큰(`t1`)과 다음 토큰(`t2`)을 동시에 비교하며 로직을 간결하게 구성했습니다.
- `compress` 내부 함수를 정의하여 코드의 가독성을 높이고, 제너레이터 표현식과 `sum()`을 사용하여 메모리 효율적으로 최종 길이를 계산합니다.

```python
def solution(s):
    def compress(s, t_size):
        tokens = [s[i:i + t_size] for i in range(0, len(s), t_size)]
        # 파이썬의 슬라이싱은 인덱스가 실제 문자열의 길이를 넘어가더라도 에러를 발생시키지 않고 대신 문자열의 끝까지만 잘라서 반환한다.

        result = []
        remember = tokens[0]
        cnt = 1

        # zip()은 여러 개의 반복 객체를 짝을 지어주는 함수
        for t1, t2 in zip(tokens, tokens[1:] + [""]):
            if t1 == t2:
                cnt += 1
            else:
                result.append((t1, cnt))
                remember = t2
                cnt = 1

        # 제너레이터: 필요할 때마다 값을 생성해서 반환하는 객체 (메모리 효율)
        return sum((len(token) + (len(str(cnt)) if cnt > 1 else 0)) for token, cnt in result)

    min_length = len(s)
    for t_size in range(1, len(s) // 2 + 1):
        t = compress(s, t_size)
        if t < min_length:
            min_length = t

    return min_length
```
