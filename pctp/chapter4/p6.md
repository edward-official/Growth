# [문제 6](https://programmers.co.kr/learn/courses/30/lessons/12926)

여기는 문제를 해결하면서 점진적으로 코드를 개선해 나간 과정을 기록하는 공간입니다.

## Version 1

- 문자열을 순회환 결과를 리스트(`temp`)에 담은 뒤, 마지막에 `join()`을 사용하여 문자열로 합치는 방식입니다.
- 대문자와 소문자의 범위를 직접 `ord()`값으로 비교하고, 범위를 넘어갈 경우 나머지와 오프셋을 계산하여 직접 보정해주는 직관적인 풀이입니다.

```python
def solution(s, n):
    answer = ''

    temp = []
    for letter in s:
        if letter is not " ":
            if ord("A") <= ord(letter) <= ord("Z"):
                if ord(letter) + n <= ord("Z"):
                    temp.append(chr(ord(letter) + n))
                else:
                    temp.append(chr((ord(letter) + n) % ord("Z") + ord("A") - 1))
            elif ord("a") <= ord(letter) <= ord("z"):
                if ord(letter) + n <= ord("z"):
                    temp.append(chr(ord(letter) + n))
                else:
                    temp.append(chr((ord(letter) + n) % ord("z") + ord("a") - 1))
        else:
            temp.append(" ")

    return answer.join(temp)
```

## Version 2

- 문자열을 리스트로 변환하여 내부에서 직접 수정하는 방식입니다.
- 알파벳의 전체 개수(`26`)를 직접 사용하는 대신, `ord("Z") - ord("A") + 1`과 같은 식을 사용하여 수치의 의미를 명확히 했습니다.
- `(현재 값 - 오프셋 + 이동 거리) % 26 + 오프셋` 공식을 적용하여 Version 1보다 훨씬 간결하고 세련되게 구현되었습니다.

```python
def solution(s, n):
    s = list(s)

    for idx, letter in enumerate(s):
        if letter == " ":
            continue
        t = ord("A") if ord(letter) <= ord("Z") else ord("a")
        s[idx] = chr((ord(letter) - t + n) % (ord("Z") - ord("A") + 1) + t)

    return "".join(s)
```
