# [문제 8](https://school.programmers.co.kr/learn/courses/30/lessons/64065)

여기는 문제를 해결하면서 점진적으로 코드를 개선해 나간 과정을 기록하는 공간입니다.

## Version 1

- 문자열을 전처리하여 집합별로 분리하고 길이 순으로 정렬합니다.
- 중복 여부를 확인하기 위해 리스트(`answer`)에서 `in` 연산을 사용합니다.
- 데이터가 많아질 경우 리스트 순회 비용으로 인해 전체 복잡도가 $O(N^2)$에 가까워질 수 있습니다.

```python
def solution(s):
    answer = []

    tokens = s[2:-2].split("},{")
    tokens.sort(key = len)
    for token in tokens:
        for n in token.split(","):
            n = int(n)
            if n not in answer:
                answer.append(n)

    return answer
```

## Version 2

- 중복 확인의 성능을 개선하기 위해 딕셔너리(`answer`)를 활용합니다.
- 딕셔너리의 키 조회는 $O(1)$이므로, 전체적인 시간 복잡도를 $O(N \log N)$ 수준으로 단축할 수 있습니다.
- 마지막에 딕셔너리의 키들을 리스트로 변환하여 결과를 반환합니다.

```python
def solution(s):
    answer = {}

    tokens = s[2:-2].split("},{")
    tokens.sort(key = len)
    for token in tokens:
        for n in token.split(","):
            n = int(n)
            if n not in answer:
                answer[n] = -1

    return list(answer)
```
