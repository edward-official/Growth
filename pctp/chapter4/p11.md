# [문제 11](https://programmers.co.kr/learn/courses/30/lessons/68935)

여기는 문제를 해결하면서 점진적으로 코드를 개선해 나간 과정을 기록하는 공간입니다.

## Version 1

- `radix_change` 함수를 직접 구현하여 10진수를 n진수로 변환합니다. (10진수 이상의 진법 처리를 위해 `chr(ord("A") + r - 10)` 로직이 포함되어 있습니다.)
- 변환된 3진수 문자열 `t`를 순회하며 각 자리 숫자에 $3^{idx}$를 곱해 10진수로 재변환합니다.
- 파이썬의 `int(string, 3)` 내장 기능을 사용하는 대신, 인덱스(`idx`)를 활용해 가중치를 곱하는 방식으로 직접 계산했습니다.

```python
def radix_change(n, radix):
    if n == 0:
        return "0"
    res = []

    while n:
        n, r = divmod(n, radix)
        if r < 10:
            res.append(str(r))
        else:
            res.append(chr(ord("A") + r - 10))

    return "".join(reversed(res))

def solution(n):
    t = radix_change(n, 3)
    answer = 0

    for idx, item in enumerate(t):
        answer += int(item) * (3 ** idx)

    return answer
```

## Version 2

- 10진수로 재변환할 때 파이썬의 강력한 내장 함수인 `int(string, base)`를 활용했습니다.
- `t[::-1]`을 통해 3진수 문자열을 뒤집은 뒤, `int(..., 3)`을 호출하여 훨씬 간결하게 결과를 도출합니다.

```python
def radix_change(n, radix):
    if n == 0:
        return "0"
    res = []

    while n:
        n, r = divmod(n, radix)
        if r < 10:
            res.append(str(r))
        else:
            res.append(chr(ord("A") + r - 10))

    return "".join(reversed(res))

def solution(n):
    t = radix_change(n, 3)
    return int(t[::-1], 3)
```
