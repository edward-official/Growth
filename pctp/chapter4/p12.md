# [문제 12](https://programmers.co.kr/learn/courses/30/lessons/70129)

여기는 문제를 해결하면서 점진적으로 코드를 개선해 나간 과정을 기록하는 공간입니다.

## Version 1

- 문제의 요구사항을 각 단계별 함수로 분리하여 명시적으로 구현한 방식입니다.
- `count_binary`: 0과 1의 개수를 직접 세어 변환될 길이와 제거될 0의 개수를 계산합니다.
- `radix_convert`: 직접 진법 변환 로직을 작성하여 10진수를 2진수로 변환합니다.
- `full_process`: 제거와 변환 과정을 하나의 단위로 묶어 처리합니다.

```python
def count_binary(s):
    cnt = 0
    for letter in s:
        if letter == "1":
            cnt += 1
    return len(s) - cnt, cnt

def radix_convert(n, radix):
    res = []

    while n:
        n, r = divmod(n, radix)
        res.append(str(r) if r < 10 else str(ord("A") + r - 10))

    return "".join(reversed(res))

def full_process(s):
    cnt_0, cnt_1 = count_binary(s)
    return cnt_0, radix_convert(cnt_1, 2)

def solution(s):
    cnt_process = 0
    n_deleted = 0
    while s != "1":
        cnt_process += 1
        t_deleted, s = full_process(s)
        n_deleted += t_deleted
    return [cnt_process, n_deleted]
```

## Version 2

- 파이썬의 내장 함수를 활용하여 기능을 압축하고 효율성을 높인 방식입니다.
- `count("0")`과 `count("1")`을 사용하여 불필요한 루프와 함수 호출을 줄였습니다.
- `bin()[2:]`를 사용하여 진법 변환을 한 줄로 처리했습니다.

```python
def solution(s):
    n_rep, n_del = 0, 0

    while s != "1":
        n_rep += 1
        n_del += s.count("0")
        s = bin(s.count("1"))[2:]

    return [n_rep, n_del]
```
