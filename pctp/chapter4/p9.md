# [문제 9](https://programmers.co.kr/learn/courses/30/lessons/12973)

여기는 문제를 해결하면서 점진적으로 코드를 개선해 나간 과정을 기록하는 공간입니다.

## Version 1

- 스택(Stack) 자료구조를 활용하여 인접한 동일 문자를 효율적으로 제거하는 방식입니다.
- 문자열을 한 번만 순회($O(N)$)하면서, 스택의 최상단 문자가 현재 문자와 같으면 제거(`pop`)하고, 다르면 추가(`append`)합니다.
- 순회가 끝난 후 스택이 비어있으면 모든 문자가 짝지어 제거된 것이므로 `1`을, 남아있으면 `0`을 반환합니다.

```python
def solution(s):
    stack_t = []
    for letter in s:
        if stack_t and stack_t[-1] == letter:
            stack_t.pop()
        else:
            stack_t.append(letter)

    return 0 if stack_t else 1
```
