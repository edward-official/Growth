## [문제 6: 시저 암호](https://programmers.co.kr/learn/courses/30/lessons/12926)

### 나의 풀이

```python
def updated_letter(letter, n):
    if letter == " ":
        return " "
    elif "A" <= letter <= "Z":
        if ord(letter) + n <= ord("Z"):
            return chr(ord(letter) + n)
        else:
            return chr(ord("A") + (ord(letter) + n) % ord("Z") - 1)
    elif "a" <= letter <= "z":
        if ord(letter) + n <= ord("z"):
            return chr(ord(letter) + n)
        else:
            return chr(ord("a") + (ord(letter) + n) % ord("z") - 1)

def solution(s, n):
    box = list(s)
    for idx, letter in enumerate(box):
        box[idx] = updated_letter(letter, n)
    return "".join(box)
```

## [문제 7: 이상한 문자 만들기](https://programmers.co.kr/learn/courses/30/lessons/12930)

### 나의 풀이

```python
def solution(s):
    box = list(s)
    _order = -1

    for idx, letter in enumerate(box):
        _order += 1
        if letter == " ":
            _order = -1
        elif _order % 2 == 0:
            box[idx] = letter.upper()
        else:
            box[idx] = letter.lower()

    return "".join(box)
```

## [문제 8: 튜플](https://school.programmers.co.kr/learn/courses/30/lessons/64065)

### 나의 풀이

```python
def solution(s):
    answer = []

    _list = s[2:-2].split("},{")
    _list.sort(key = lambda x: len(x))
    for subset in _list:
        elements = subset.split(",")
        for e in elements:
            if int(e) not in answer:
                answer.append(int(e))
                break

    return answer
```
