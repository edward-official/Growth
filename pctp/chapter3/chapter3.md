## 2차원 배열 이해하기

코딩 테스트에서 배열은 가장 기본이자 반드시 등장하는 핵심 개념입니다. 여기서는 배열, 특히 2차원 배열을 이해하고 이를 어떻게 바라봐야 하는지 정리합니다.

### 파이썬에서의 배열

파이썬에는 다른 언어처럼 “고정 크기 배열”이 기본 자료형으로 존재하지 않습니다.

- 변수 선언 시 자료형을 따로 명시하지 않습니다.
- 고정된 크기만 저장하는 전통적인 배열도 없습니다.
- 대신 여러 데이터를 담을 수 있는 `list`가 존재합니다.

문제에서 “배열”을 사용하라고 하면, 실제로는 리스트를 사용하는 것입니다.
데이터 조회 및 수정 방식은 다른 언어의 배열과 거의 동일하므로, 특별히 리스트의 특성을 강조할 필요가 없는 경우 이후 설명에서는 ‘배열’이라고 부르겠습니다.

## 1차원 배열과 2차원 배열

### 배열의 기본 개념

배열은 한 변수에 여러 데이터를 연속적으로 저장할 수 있는 1차원 자료 구조입니다.
즉, 데이터를 순서대로 나열해 저장하는 구조입니다.

### 2차원 배열이란?

2차원 배열은 “배열 안에 배열을 넣은 형태”입니다.

예:

```python
data = [[1, 2, 3], [4, 5, 6]]
```

이 구조는 다음과 같이 이해할 수 있습니다.

- 바깥 리스트: 여러 개의 행(row)
- 안쪽 리스트: 각 행에 해당하는 열(column) 데이터

2차원 배열은 복잡한 개념이 아닙니다.
요소가 또 다른 배열이라고 생각하면 됩니다.

### 1차원 배열의 접근 방식

1차원 배열은 한 방향(가로 방향)으로 데이터가 연속 저장됩니다.

```python
array1 = [0, 0, 0, 0]
```

- 첫 번째 요소 → `array1[0]`
- 세 번째 요소 → `array1[2]`

인덱스는 0부터 시작합니다.
N개의 데이터가 있다면 마지막 인덱스는 `N - 1`입니다.

### 2차원 배열의 구조와 접근 방식

2차원 배열은 직사각형 형태로 생각할 수 있습니다.

- 가로 방향 → 열(column)
- 세로 방향 → 행(row)

접근 방식은 다음과 같습니다.

```python
array[행][열]
```

즉,

1. 먼저 세로 위치(행)를 선택하고
2. 그 다음 가로 위치(열)를 선택합니다.

예를 들어 `(1, 2)` 위치에 접근한다면:

```python
array[1][2]
```

좌표 개념으로 이해해도 좋습니다.
항상 “행 먼저, 열 나중” 순서라는 점이 중요합니다.

## 배열을 다양하게 생각하기

1차원 배열과 2차원 배열의 구조를 이해했다면, 이제 2차원 배열을 어떻게 활용할지 생각해봅시다.

### 2차원 배열의 핵심: 그룹

1차원 배열은 단순히 많은 데이터를 나열한 구조입니다.
반면 2차원 배열은 데이터를 그룹 단위로 묶어 의미를 부여하는 구조입니다.

코딩 테스트에서 제공되는 2차원 배열은 보통 다음과 같은 특징을 가집니다.

- 각 행의 길이가 동일한 직사각형 구조
- 특정 패턴이나 계산 규칙이 존재
- 모양을 만들거나 변형하는 문제로 출제

### 2차원 배열을 이미지처럼 생각하기

2차원 배열을 숫자 집합으로만 보면 문제 풀이가 느려질 수 있습니다.

예를 들어, 각 원소가 0~255 범위를 가진다면 이를 단순 숫자가 아니라 “이미지의 픽셀 밝기”라고 생각할 수 있습니다.

이렇게 보면:

- 배열 일부를 자른다 → 이미지 일부를 자른다
- 배열을 회전한다 → 이미지를 회전한다
- 배열을 뒤집는다 → 이미지를 뒤집는다

배열을 이미지처럼 생각하면 문제를 직관적으로 이해할 수 있습니다.
특히 모양을 만들거나 회전·대칭을 다루는 문제에서 매우 유용합니다.

### 계산 위주 접근의 한계

모든 경우를 수학적으로만 계산하려고 하면:

- 사고 과정이 복잡해지고
- 시간 소모가 커질 수 있습니다.

하지만 배열을 “형태”로 이해하면:

- 구조 파악이 빨라지고
- 전략 수립이 쉬워집니다.

문제를 읽고 배열을 보았을 때,
“이 배열은 어떤 모양이며 어떻게 변형할 수 있는가?”를 먼저 생각하는 습관이 중요합니다.

## 1차원 배열로 2차원 배열을 대신할 수 있을까?

배열은 본질적으로 연속된 데이터 집합입니다.
컴퓨터 입장에서 2차원 배열도 결국 1차원 메모리의 연속 구조입니다.

따라서 이론적으로는:

```python
data[a][b]
```

를

```python
data[a * width + b]
```

처럼 1차원으로 변환해 사용할 수 있습니다.

이 방법은:

- 2차원 배열을 1차원으로 펼치는(flatten) 방식
- 배열의 가로 길이(width)가 고정되어 있을 때 사용 가능
- 인덱스 계산을 통해 동일한 접근 가능

하지만 대부분의 상황에서는 굳이 2차원 배열을 1차원으로 바꿀 필요가 없습니다.

- 2차원 구조가 사람 입장에서 이해하기 쉽고
- 코드 가독성이 좋으며
- 문제의 의도와 잘 맞기 때문입니다.

특별한 성능 최적화 목적이 아니라면, 주어진 2차원 구조를 그대로 사용하는 것이 일반적으로 가장 바람직합니다.
