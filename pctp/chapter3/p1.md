# [문제 1](https://school.programmers.co.kr/learn/courses/30/lessons/87377)

여기는 문제를 해결하면서 점진적으로 코드를 개선해 나간 과정을 기록하는 공간입니다.

## 버전 1

- 교점 계산 공식(Cramer's rule)을 활용하여 두 직선의 교점을 구합니다.
- 정수 교점만 필터링하여 리스트에 저장합니다.
- 교점들의 최소/최대 좌표를 구해 별을 그릴 보드의 크기를 결정합니다.
- 보드에 별('\*')과 빈 공간('.')을 채워 결과를 리턴합니다.

```python
def cross_point(line1, line2):
    a, b, e = line1
    c, d, f = line2
    if (a * d - b * c) == 0:
        return None
    elif (b * f - e * d) % (a * d - b * c) != 0:
        return None
    elif (e * c - a * f) % (a * d - b * c) != 0:
        return None
    else:
        return ((b * f - e * d) // (a * d - b * c), (e * c - a * f) // (a * d - b * c))

def solution(lines):
    points = []
    for idx1 in range(len(lines)):
        for idx2 in range(idx1 + 1, len(lines)):
            t = cross_point(lines[idx1], lines[idx2])
            if t:
                points.append(t)

    x_max = max([p[0] for p in points])
    x_min = min([p[0] for p in points])
    y_max = max([p[1] for p in points])
    y_min = min([p[1] for p in points])

    board = [["." for j in range(x_max - x_min + 1)] for i in range(y_max - y_min + 1)]
    for x, y in points:
        board[y_max - y][x - x_min] = "*"

    return ["".join(r) for r in board]
```
