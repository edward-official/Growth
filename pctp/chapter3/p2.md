# [문제 2](https://school.programmers.co.kr/learn/courses/30/lessons/77485)

여기는 문제를 해결하면서 점진적으로 코드를 개선해 나간 과정을 기록하는 공간입니다.

## Version 1

- 시작점(우측 상단)부터 4방향(우측 ↓, 하단 ←, 좌측 ↑, 상단 →)으로 순차적으로 값을 밀어내는 직관적인 풀이.
- 값이 유실되지 않도록 `temp`와 `next_temp` 변수를 사용하여 이동할 위치의 기존 값을 임시로 보관하며 계속 한 칸씩 전진합니다.
- `의식의 흐름`대로 구현한 가장 기본적이고 무작정 부딪혀본 첫 번째 풀이입니다.

```python
def solution(rows, columns, queries):
    board = initBoard(rows, columns)
    answer = []
    for q in queries:
        t = rotate(board, q)
        answer.append(t)
    return answer

def initBoard(r, c):
    return [[i * c + j + 1 for j in range(c)] for i in range(r)]

def rotate(board, query):
    x1, y1, x2, y2 = [e - 1 for e in query]
    temp = board[x1][y2]
    min_val = temp

    # 1. 우측 테두리 (위 -> 아래)
    for x in range(x1, x2):
        next_temp = board[x + 1][y2]
        board[x + 1][y2] = temp
        temp = next_temp
        if temp < min_val:
            min_val = temp

    # 2. 하단 테두리 (오른쪽 -> 왼쪽)
    for y in range(y2, y1, -1):
        next_temp = board[x2][y - 1]
        board[x2][y - 1] = temp
        temp = next_temp
        if temp < min_val:
            min_val = temp

    # 3. 좌측 테두리 (아래 -> 위)
    for x in range(x2, x1, -1):
        next_temp = board[x - 1][y1]
        board[x - 1][y1] = temp
        temp = next_temp
        if temp < min_val:
            min_val = temp

    # 4. 상단 테두리 (왼쪽 -> 오른쪽)
    for y in range(y1, y2):
        next_temp = board[x1][y + 1]
        board[x1][y + 1] = temp
        temp = next_temp
        if temp < min_val:
             min_val = temp

    return min_val
```

## Version 2

- 값을 덮어쓰기 전에 필요한 `temp` 변수를 하나만 사용하기 위해, 회전 방향의 역순(반대 방향)으로 요소를 당겨오는 방식을 사용했습니다.
- 이를 통해 첫 번째 버전에서 발생했던 과도한 변수 할당을 줄이고 좀 더 효율적으로 값을 회전시킬 수 있었습니다.

```python
def solution(rows, columns, queries):
    board = [[r * columns + c + 1 for c in range(columns)] for r in range(rows)]

    def rotate(board, query):
        x1,y1,x2,y2 = [n - 1 for n in query]
        t = board[x2][y2]
        min_ = t

        for x in range(x2, x1, -1):
            board[x][y2] = board[x - 1][y2]
            if board[x][y2] < min_:
                min_ = board[x][y2]

        for y in range(y2, y1, -1):
            board[x1][y] = board[x1][y - 1]
            if board[x1][y] < min_:
                min_ = board[x1][y]

        for x in range(x1, x2):
            board[x][y1] = board[x + 1][y1]
            if board[x][y1] < min_:
                min_ = board[x][y1]

        for y in range(y1, y2):
            board[x2][y] = board[x2][y + 1]
            if board[x2][y] < min_:
                min_ = board[x2][y]

        board[x2][y2 - 1] = t

        return min_

    answer = []
    for q in queries:
        t = rotate(board, q)
        answer.append(t)

    return answer
```

## Version 3

- 파이썬의 **슬라이싱(`[:]`)** 기능을 활용하여 상단과 하단 테두리의 요소들을 한 번에 이동시키는 방식으로 최적화했습니다.
- 좌우 테두리만 반복문으로 처리하여 연산 횟수를 줄이고 코드의 가독성을 크게 높인 풀이입니다.

```python
def solution(rows, columns, queries):
    answer = []
    board = [[r * columns + c + 1 for c in range(columns)] for r in range(rows)]

    def rotate(board, query):
        x1, y1, x2, y2 = [e - 1 for e in query]
        min_ = board[x1][y1]

        row1 = board[x1][y1:y2]
        row2 = board[x2][y1 + 1: y2 + 1]

        for x in range(x1, x2):
            board[x][y1] = board[x + 1][y1]
            if board[x][y1] < min_:
                min_ = board[x][y1]
        for x in range(x2, x1, -1):
            board[x][y2] = board[x - 1][y2]
            if board[x][y2] < min_:
                min_ = board[x][y2]

        board[x1][y1 + 1:y2 + 1] = row1
        board[x2][y1:y2] = row2

        t = min(row1 + row2)
        if t < min_:
            min_ = t

        return min_

    for q in queries:
        t = rotate(board, q)
        answer.append(t)

    return answer
```
