# [문제 3](https://school.programmers.co.kr/learn/courses/30/lessons/68645)

여기는 문제를 해결하면서 점진적으로 코드를 개선해 나간 과정을 기록하는 공간입니다.

## Version 1

- 바깥쪽 테두리의 삼각형(아래, 오른쪽, 왼쪽 위 대각선)부터 안쪽으로 층층이 채워나가는 방식입니다.
- 테두리의 크기(`width`)가 3씩 줄어드는 규칙을 활용하여 `triangle` 함수로 반복 처리하고, 남은 변의 길이가 1이나 2일 때는 `finish1`, `finish2`로 예외적인 부분을 처리하도록 설계되어 있습니다.
- `의식의 흐름`대로 달팽이의 이동 규칙을 단계별로 분리하여 각 변의 길이에 맞게 직접적으로 값을 수동 할당하는 직관적인 첫 번째 풀이입니다.

```python
def solution(n):
    answer = []
    board = [[-1 for i in range(n)] for j in range(n)]

    def triangle(board, width, open_value, open_x, open_y):
        for t in range(width):
            board[open_x + t][open_y] = open_value + t
        for t in range(width):
            board[open_x + width - 1][open_y + t] = open_value + width - 1 + t
        for t in range(width - 1):
            board[open_x + width - 1 - t][open_y + width - 1 - t] = open_value + 2 * width - 2 + t

        return open_value + 3 * width - 3

    open_value = 1
    width = n
    open_x = 0
    open_y = 0
    for _ in range(n // 3):
        open_value = triangle(board, width, open_value, open_x, open_y)
        width -= 3
        open_x += 2
        open_y += 1

    def finish1(board, width, open_value, open_x, open_y):
        for t in range(width):
            board[open_x + t][open_y] = open_value + t

    def finish2(board, width, open_value, open_x, open_y):
        for t in range(width):
            board[open_x + t][open_y] = open_value + t
        for t in range(width):
            board[open_x + width - 1][open_y + t] = open_value + width - 1 + t

    if n % 3 == 1:
        finish1(board, 1, open_value, open_x, open_y)
    elif n % 3 == 2:
        finish2(board, 2, open_value, open_x, open_y)

    for i in range(n):
        answer += board[i][0 : i + 1]

    return answer
```
