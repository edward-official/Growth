# [문제 4](https://programmers.co.kr/learn/courses/30/lessons/81302)

여기는 문제를 해결하면서 점진적으로 코드를 개선해 나간 과정을 기록하는 공간입니다.

## Version 1

- BFS와 같은 탐색 알고리즘 대신, 체크해야 할 거리별 이동 배열(`options_1`, `options_2`, `options_3`)을 미리 정의해 두고 `for`문을 이용해 규칙성 있게 검사합니다.
- 특정 거리의 패턴마다 위반 조건을 판단하여, 파티션(`X`)의 여부에 따라 통과/실패를 결정하는 직관적인 풀이 방식입니다.

```python
def solution(places):
    answer = []

    def check_around(place, r, c):
        options_1 = [(2, 0), (-2, 0), (0, 2), (0, -2)]
        options_2 = [(1, 0), (-1, 0), (0, 1), (0, -1)]
        options_3 = [(1, 1), (1, -1), (-1, 1), (-1, -1)]

        for dr, dc in options_1:
            if 0 <= r + dr < 5 and 0 <= c + dc < 5 and place[r + dr][c + dc] == "P":
                if place[r + dr // 2][c + dc // 2] != "X":
                    return False

        for dr, dc in options_2:
            if 0 <= r + dr < 5 and 0 <= c + dc < 5 and place[r + dr][c + dc] == "P":
                return False

        for dr, dc in options_3:
            if 0 <= r + dr < 5 and 0 <= c + dc < 5 and place[r + dr][c + dc] == "P":
                if not (place[r + dr][c] == "X" and place[r][c + dc] == "X"):
                    return False

        return True

    def check_room(place):
        for r in range(5):
            for c in range(5):
                if place[r][c] == "P" and not check_around(place, r, c):
                    return 0
        return 1

    for p in places:
        answer.append(check_room(p))

    return answer
```
